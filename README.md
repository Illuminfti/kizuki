# Kizuki

気づき — awareness; the moment of realization.

**Your life, queryable as a CLI and MCP.** Local-first: your digital life
captured into a durable queue, distilled into staged proposals, reviewed and
promoted by *you* into a canonical Markdown world model on your own disk,
served read-only to any agent from any harness. Kizuki is not a harness and
hosts no agents.

## Pledges

- **Free local forever.** The local product is MIT and complete. Recall is
  never metered.
- **Zero phone-home.** No telemetry, no crash reports, no update checks — the
  only network calls are your configured connectors and your configured model
  endpoint. CI enforces this.
- **Your files.** Canon is Markdown on your disk. Deleting Kizuki leaves a
  readable vault.
- **Nothing writes canon but you.** Agents and automation can only propose.

## Status

Pre-alpha. Building in the open; this README claims only what runs. Nothing
