# Core semantic qualification at prepared admission

`core-semantic-v2` evaluates the actual production `prepareWorldDrafts` output.
It is a prospective method. The retained prior split and scripted answers are
unaccepted development controls; they do not qualify a prior observed campaign.
A fresh sealed split and a separate review of its actual responses are required.
Every actual call requires the current corpus, contract and method files to be frozen together before execution.

## Two distinct results

The raw model result keeps the existing typed, identity, role, time and usage
checks. Raw citation precision remains failed when a claim omits the reporting
words from its own citations. Host context never becomes model-authored evidence
and never relabels this diagnostic as passed.

The prepared result calls the production function with an immutable synthetic
fixture derived only from the exact case input. The host-attested window is the
full input event, which this nonsegmented runner sends to the model. It also calls
the same function without windows to record the original guard outcome. Each call uses a fresh in-memory ledger and the journal’s actual registry check
and in-order pending classification callback; that initial empty context is
bound in the fixture manifest. The ledger is query-only after initialization and
closed afterward. Both calls must produce one admission per claim with zero drops. A guard downgrade,
changed literal, role, time, body, confidence or authority fails qualification.
Only ordinary reference resolution and appending the exact sent window to
perspective anchors are permitted. Original anchors, per-item and aggregate caps
remain enforced. The evaluator does not implement context normalization.

Reporting-role coverage uses the actual prepared admission's anchors. Coverage is
not a semantic entailment proof: independent review must still check that the
particular actor, role, proposition and time are supported together. An unrelated
reporting verb elsewhere in the window cannot justify a claim. Unsupported
additions, wrong actor or role, literal/body conflicts and forbidden
interpretations still fail that review.

## Exact evidence binding

Reports retain raw observations and transport traces unchanged. Each prepared
case records the input fixture manifest, sent-window manifest, canonical actual
admissions and claim correspondence. The separate review uses
`kizuki.core-semantic-review/v2` with stage `prepared_admission` and binds the exact
report and Core source commit, corpus and contract, canonical transport response
payload, parsed response, fixture, sent windows and admissions. It reviews every
required fact, role/time relationship, legacy extra and forbidden interpretation.
The report remains `pending_manual_review`; only the unchanged receipt-verifier
flow with this exact independent artifact can accept it.

The runner fingerprint includes the production preparation, guard, occurrence,
semantic-contract and extraction/window source files. Any change to these files
invalidates prior method evidence. No model prompt, vocabulary, corpus answer or
production grant changes are part of this method.
